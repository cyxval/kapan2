FOOD COURT KAPAN — LOCAL PROJECT

Requirements:
- Node.js 20+ (recommended)
- Bun (https://bun.sh)

Run locally:
1. Extract this ZIP.
2. Open a terminal in the extracted project folder (the folder containing package.json).
3. Run: bun install
4. Run: bun run dev
5. Open the local URL printed in the terminal (usually http://localhost:5173).

Production checks:
- bun run typecheck
- bun run build

Notes:
- All supplied restaurant photos and scroll-animation media are in public/assets/world/.
- The menu and prices were not supplied, so the site directs visitors to call for today's menu instead of inventing prices.
- This archive contains the full project source and configuration, not node_modules or deployment credentials.
